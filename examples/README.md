# Примеры дней

Все примеры сгенерированы прототипом кнопкой «Добавить 5 демо-дней» и выгружены функцией «Скачать папку дня». Названия папок придуманы системой.

| Папка (название от системы) | Настроение | Техника | Песня | Ключевые решения |
|---|---|---|---|---|
| [Вечер осенью в парке с девушкой](Вечер%20осенью%20в%20парке%20с%20девушкой/) | спокойствие | Клод Моне | Frank Sinatra — Fly Me to the Moon, 1964 | 90 BPM, мажор → тепло и медленно; осень → охра; песня до 1980 → выцветание и зерно |
| [Ночь в офисе перед сдачей](Ночь%20в%20офисе%20перед%20сдачей/) | напряжение | Кандинский | M83 — Midnight City, 2011 | 138 BPM, минор, энергия 85% → много фигур, слайд каждые 3,5 с; ночь → тёмный фон |
| [Вечер летом у моря с друзьями](Вечер%20летом%20у%20моря%20с%20друзьями/) | радость | плёночная фотография | Pharrell Williams — Happy, 2013 | энергия 80% → сильное зерно; лето → насыщенность +15% |
| [Серый день дома](Серый%20день%20дома/) | тихая грусть | японский минимализм | Erik Satie — Gymnopédie No.1, 1888 | 70 BPM, минор → почти без цвета, слайд каждые 6,9 с |
| [Утро зимой дома с семьёй](Утро%20зимой%20дома%20с%20семьёй/) | спокойствие | Клод Моне | Wham! — Last Christmas, 1984 | утро → светлый фон; зима → насыщенность −30%; 80-е → лёгкое зерно |

- [все-слайды.jpg](все-слайды.jpg) — все карусели: одна строка — один день.
