# Использованные инструменты

## Библиотеки

Сторонних JS-библиотек нет: весь код в `diary.js` написан командой.

## Браузерные API

| API | Для чего |
|---|---|
| Canvas 2D | Рисование слайдов 4:5, обработка фото (мазки, зерно, геометрия), анализ цвета снимков |
| Web Audio API (`decodeAudioData`) | Декодирование аудиофайла для анализа темпа, энергии и лада |
| Web Speech API (`speechSynthesis`) | Озвучка записи голосом, подобранным под настроение |
| IndexedDB | Хранение дней в браузере пользователя |
| CSS `@property`, `color-mix` | Плавная смена палитры сайта под настроение |
| CSS-анимации, `backdrop-filter`, SVG `feTurbulence` | Motion-дизайн интерфейса: появления, стекло, плёночное зерно; эквалайзер и полоса прогресса в темпе песни |
| Pointer Events | Свет за курсором и 3D-наклон карточек (только мышь) |

## Алгоритмы (реализованы командой по открытым описаниям)

- **Темп** — огибающая громкости (RMS, окна 10 мс) → всплески → нормированная автокорреляция в диапазоне 60–180 BPM с выбором самого короткого устойчивого периода.
- **Лад и тональность** — хрома-вектор через алгоритм Гёрцеля (36 нот, 3 октавы) и корреляция с тональными профилями Крумханзля — Кесслера (Krumhansl & Kessler, 1982).
- **Доминирующий цвет** — гистограмма оттенков (12 корзин) с весом по насыщенности по всем фото дня.
- **Псевдослучайность** — генератор mulberry32 с зерном дня: одна и та же запись даёт один и тот же рисунок мазков.
- **ZIP** — запись архива без сжатия (формат PKWARE APPNOTE, CRC-32, UTF-8 имена файлов).

## Готовые ресурсы

- Шрифты **Cormorant Garamond**, **Manrope**, **Caveat** — Google Fonts, лицензия SIL Open Font License.
- Демо-«фотографии» нарисованы кодом (`scenePhoto` в `diary.js`); чужие фото не используются.
- В демо-днях указаны только названия и исполнители песен. Аудио не используется и не распространяется.
